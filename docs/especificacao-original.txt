ESPECIFICAÇÃO TÉCNICA FORMAL E ARQUITETURAL: NEXTORCH (V1.0)

Classificação: Arquitetura de Software / Deep Learning & Meta-Sistemas
Subsistemas: Meta-Síntese, Raciocínio Latente (TTC), SAE Online, Oráculo Formal,
Escala \mu P, Integração Orange Canvas
Público-Alvo: Engenheiros de Sistemas de IA e Agentes Autônomos de Codificação

1. VISÃO GERAL E FILOSOFIA DE DESIGN

O Nextorch é um framework declarativo, autônomo e auto-evolutivo para
aprendizado de máquina e dedução formal. Diferente dos paradigmas imperativos
tradicionais (como o PyTorch original), o Nextorch unifica:

1.  Síntese de Arquitetura Orientada a Variedades (Manifold-Driven Synthesis): A
    rede neural não é desenhada manualmente; sua topologia é derivada da
    assinatura geométrica do dado via amostragem generativa (GFlowNets) e
    validada em milissegundos por métricas de custo zero (Zero-Cost Proxies).
2.  Invariância de Escala via Parametrização \mu P: Garantia analítica de que
    hiperparâmetros e dinâmicas de treino encontrados em modelos de 10^5
    parâmetros transferem-se assintoticamente sem divergência para modelos de
    10^{11} parâmetros.
3.  Raciocínio Latente com Test-Time Compute (TTC): Resolução de problemas via
    busca em feixe contínua (Continuous Latent Beam Search) em espaços de
    representação antes da emissão de tokens simbólicos.
4.  Interpretabilidade Mecanicista Co-Evolutiva (Integrated SAE): Autoencoders
    esparsos nativos no gargalo latente, com ajuste dinâmico de esparsidade via
    controle PID para erradicar a deriva do espaço latente (Latent Drift).
5.  Portais de Verificação Formal Inflexíveis: Conexão nativa com provadores de
    teoremas (Lean 4) e solucionadores SMT (Z3), atuando como barreiras de
    execução para impedir a contaminação de dados sintéticos por alucinações.
6.  Integração Nativa com Orange Data Mining: Suporte bidirecional a estruturas
    Orange.data.Table e disponibilização de um pacote de widgets visuais para o
    Orange Canvas, permitindo o monitoramento visual do ciclo autônomo.

3. ESPECIFICAÇÃO MATEMÁTICA E FUNCIONAL DOS COMPONENTES

3.1. Módulo core.manifold e core.orange_bridge

Responsável pelo fingerprinting instantâneo de datasets sem treinamento
supervisionado.

  - Assinatura Espectral: Seja a matriz de dados centralizada
    \mathbf{X} \in \mathbb{R}^{N \times D}. O extrator calcula os valores
    singulares \mathbf{S} = \text{diag}(\mathbf{\Sigma}) da decomposição
    \mathbf{X} = \mathbf{U} \mathbf{\Sigma} \mathbf{V}^T sobre um mini-batch
    estratificado B \le 512.
  - Dimensão Intrínseca (d_{int}):
    d_{int} = \arg\min_k \left( \frac{\sum_{i=1}^k S_i^2}{\sum_{j=1}^{\min(N, D)} S_j^2} \ge 0.95 \right)
  - Ponte Orange:
      - O conversor mapeia colunas de Orange.data.Table preservando metadados:
          - ContinuousVariable \rightarrow Tensores com normalização espectral
            ou Z-score dinâmico.
          - DiscreteVariable \rightarrow Vetores esparsos de alta cardinalidade
            ou mapeamento de embeddings.
          - Permite exportar as features decodificadas do SAE de volta como
            atributos derivados (Orange.data.ContinuousVariable) na tabela de
            dados original.

3.2. Módulo verifier.zerocost e verifier.mup

Filtra 10^9 topologias candidatas sem retropropagação explícita de dados de
treino.

  - Isometria Dinâmica: Avalia se o Jacobiano
    \mathbf{J} = \frac{\partial \mathbf{h}_L}{\partial \mathbf{h}_0} satisfaz a
    condição unitária de valores singulares:
    \sigma_i(\mathbf{J}) \approx 1 \quad \forall i \implies \kappa(\mathbf{J}) = \frac{\sigma_{\max}(\mathbf{J})}{\sigma_{\min}(\mathbf{J})} \approx 1
  - Conservação de Fluxo Sináptico (SynFlow): Calcula a sensibilidade estrutural
    passando um vetor \mathbf{1}:
    \mathcal{R} = \mathbf{1}^T \left( \prod_{l=1}^L |\mathbf{W}_l| \right) \mathbf{1}, \quad \mathcal{S}_{SynFlow} = \sum_{l=1}^L \left\| \frac{\partial \mathcal{R}}{\partial \mathbf{W}_l} \odot \mathbf{W}_l \right\|_1
    Redes com \mathcal{S}_{SynFlow} \to 0 (bloqueio de fluxo) ou
    \mathcal{S}_{SynFlow} \to \infty (explosão) são descartadas em tempo de
    compilação.
  - Garantia \mu P (Maximal Update Parametrization): Para cada projeção de
    largura d_{model}, os pesos e taxas de aprendizado são escalonados conforme:
    \mathbf{W}_{input} \sim \mathcal{N}\left(0, \frac{1}{d_{in}}\right), \quad \mathbf{W}_{hidden} \sim \mathcal{N}\left(0, \frac{1}{d_{model}}\right), \quad \mathbf{W}_{output} \sim \mathcal{N}\left(0, \frac{1}{d_{model}^2}\right)
    \eta_{hidden} = \eta_0, \quad \eta_{output} = \eta_0 \cdot \frac{1}{d_{model}}

3.3. Módulo engine.latent_ttc (Test-Time Compute)

Abandona cadeias de texto plano intermediárias durante o processo de dedução; os
passos de inferência ocorrem na variedade contínua oculta.

  - Equação de Recorrência Latente: Dado um estado inicial
    \mathbf{h}_0 = \text{Embed}(\mathbf{x}):
    \mathbf{h}_{t+1} = \Phi(\mathbf{h}_t, \mathbf{c}_t) + \epsilon_t, \quad \epsilon_t \sim \mathcal{N}(0, \sigma^2 \mathbf{I})
    onde \Phi é uma célula contínua (ex: State-Space Duality / Continuous GRU) e
    \mathbf{c}_t é o contexto acumulado.
  - Busca em Feixe Contínua (Continuous Beam Search): Em tempo de inferência, o
    motor projeta B trajetórias paralelas. Uma cabeça de valor linear intrínseco
    estima a variância residual:
    \mathcal{V}(\mathbf{h}_t) = \text{Softplus}(\mathbf{W}_v \mathbf{h}_t + b_v)
    Trajetórias cuja incerteza cresce exponencialmente sofrem poda precoce
    (pruning); as trajetórias mais estáveis convergem para o colapso discreto
    final.

3.4. Módulo interpretability.sae (Integrated SAE)

Evita o latent drift tornando o autoencoder um componente co-treinado no grafo
principal.

  - Formulação TopK / JumpReLU: Dada a ativação intermediária de pensamento
    \mathbf{h}_t \in \mathbb{R}^d:
    \mathbf{f}(\mathbf{h}_t) = \text{TopK}\left(\text{ReLU}(\mathbf{W}_{enc}(\mathbf{h}_t - \mathbf{b}_{dec}) + \mathbf{b}_{enc}), k\right)
    \hat{\mathbf{h}}_t = \mathbf{W}_{dec} \mathbf{f}(\mathbf{h}_t) + \mathbf{b}_{dec}
    com a restrição de norma unitária em colunas:
    \|\mathbf{W}_{dec, : , i}\|_2 = 1.
  - Controlador PID de Esparsidade: O hiperparâmetro de penalização \lambda_{L1}
    é ajustado a cada iteração n:
    e[n] = \|\mathbf{f}(\mathbf{h}_t)\|_0 - L_0^{target}
    \lambda_{L1}[n] = \lambda_{L1}[n-1] + K_p e[n] + K_i \sum_{j=0}^n e[j] + K_d (e[n] - e[n-1])

3.5. Módulo formal (Gateways Z3 e Lean 4)

Garante integridade matemática absoluta de novos dados sintetizados.

  - Protocolo de Refutação no Z3: Dada uma base de axiomas \Gamma e uma hipótese
    gerada pelo modelo \alpha:
    \text{Válido}(\Gamma \models \alpha) \iff \text{Solver.Check}(\Gamma \cup \{\neg \alpha\}) == \text{UNSAT}
  - Bridge Lean 4: Comunicação assíncrona com processo lake env lean --server. A
    proposta de prova formal emitida em código Lean é submetida ao REPL; se a
    compilação validar os tipos dependentes sem axiomas adicionais espúrios
    (sorry), o teorema é promovido ao dataset permanente.

3.6. Módulo evolution (Loop de Autoaperfeiçoamento e Net2Net)

  - Replay Buffer com Prova Acoplada: O buffer armazena pares
    (\mathbf{x}, \mathbf{y}^*, \Pi_{formal}), onde \Pi_{formal} é a árvore de
    passos de prova formal que o verificador aprovou.
  - Operador de Expansão Net2Net: Quando a perda no buffer validado atinge um
    platô (\Delta \mathcal{L} < \epsilon), o Nextorch amplia a matriz
    \mathbf{W} \in \mathbb{R}^{m \times n} para
    \mathbf{W}' \in \mathbb{R}^{m' \times n'} via replicação balanceada por
    ruído:
    \mathbf{W}'_{new} = \frac{1}{\sqrt{k}} \mathbf{W}_{old} + \mathcal{N}(0, 10^{-5})
    preservando perfeitamente a saída funcional
    F_{\mathbf{W}'}(\mathbf{x}) \equiv F_{\mathbf{W}}(\mathbf{x}) no momento do
    crescimento elástico.

class OrangeBridge:
    """Conversor bidirecional entre Orange.data.Table e tensores Nextorch."""
    @staticmethod
    def table_to_tensors(table: Any) -> Tuple[torch.Tensor, Optional[torch.Tensor]]:
        if not ORANGE_AVAILABLE:
            raise RuntimeError("Orange Data Mining não está instalado no ambiente.")
        
        X = torch.tensor(table.X, dtype=torch.float32)
        y = None
        if table.Y is not None and len(table.Y.shape) > 0:
            y = torch.tensor(table.Y, dtype=torch.long if table.domain.has_discrete_class else torch.float32)
        return X, y

    @staticmethod
    def tensors_to_table(X: torch.Tensor, feature_names: List[str]) -> Any:
        if not ORANGE_AVAILABLE:
            raise RuntimeError("Orange Data Mining não está instalado no ambiente.")
        
        variables = [ContinuousVariable(name) for name in feature_names]
        domain = Domain(variables)
        return Table.from_numpy(domain, X.detach().cpu().numpy())


class ManifoldAnalyzer:
    """Extrai assinaturas topológicas e invariâncias geométricas do dataset."""
    @staticmethod
    def compute_spectral_signature(X: torch.Tensor) -> Dict[str, Any]:
        N, D = X.shape
        batch = X[:min(N, 512)]
        batch_centered = batch - batch.mean(dim=0, keepdim=True)
        
        # SVD para extração da variedade latente
        _, S, _ = torch.svd(batch_centered)
        var_explained = torch.cumsum(S**2, dim=0) / torch.sum(S**2)
        intrinsic_dim = int((var_explained < 0.95).sum().item()) + 1
        
        spectral_decay = (S[0] / (S[-1] + 1e-7)).item()
        return {
            "n_samples": N,
            "input_dim": D,
            "intrinsic_dim": intrinsic_dim,
            "spectral_decay": spectral_decay,
            "singular_values": S.detach().cpu()
        }

# 2. VERIFICADOR DE CUSTO ZERO E PARAMETRIZAÇÃO muP
# =====================================================================
class ZeroCostVerifier:
    """Avalia viabilidade e fluxo dinâmico da arquitetura em t=0 sem treino."""
    @staticmethod
    def check_dynamic_isometry(model: nn.Module, input_shape: Tuple[int, ...]) -> float:
        model.eval()
        x = torch.randn(*input_shape, requires_grad=True)
        out = model(x)
        if isinstance(out, tuple):
            out = out[0]
            
        dummy_grad = torch.randn_like(out)
        grads = torch.autograd.grad(out, x, grad_outputs=dummy_grad, retain_graph=False, create_graph=False)[0]
        
        # Razão de preservação de norma do Jacobiano
        norm_in = dummy_grad.norm().item() + 1e-8
        norm_out = grads.norm().item() + 1e-8
        ratio = norm_out / norm_in
        return ratio

    @staticmethod
    def compute_synflow(model: nn.Module, input_shape: Tuple[int, ...]) -> float:
        """Calcula conservação de fluxo sináptico através das camadas."""
        model.eval()
        model.zero_grad()
        
        # Passagem com matriz unitária para testar capacidade estrutural
        x = torch.ones(*input_shape)
        out = model(x)
        if isinstance(out, tuple):
            out = out[0]
            
        metric = out.sum()
        metric.backward()
        
        total_synflow = 0.0
        for param in model.parameters():
            if param.grad is not None:
                total_synflow += (param.grad * param).abs().sum().item()
        
        model.zero_grad()
        return total_synflow


class MuPScaleCoordinator:
    """Implementa a Maximal Update Parametrization (muP) para garantia de escala."""
    @staticmethod
    def apply_mup_coordinates(model: nn.Module, d_model: int):
        for name, module in model.named_modules():
            if isinstance(module, nn.Linear):
                if "head" in name:
                    # Camada de saída: variância escalada por 1 / d_model^2
                    nn.init.normal_(module.weight, mean=0.0, std=1.0 / (d_model))
                else:
                    # Camadas internas: variância escalada por 1 / d_model
                    nn.init.normal_(module.weight, mean=0.0, std=1.0 / math.sqrt(d_model))
                if module.bias is not None:
                    nn.init.zeros_(module.bias)

# 3. ENGINE DE RACIOCÍNIO LATENTE (TEST-TIME COMPUTE)
# =====================================================================
class LatentThoughtBlock(nn.Module):
    """Célula recorrente contínua para computação latente profunda (TTC)."""
    def __init__(self, d_model: int):
        super().__init__()
        self.d_model = d_model
        self.state_gate = nn.Linear(d_model * 2, d_model)
        self.candidate_transform = nn.Sequential(
            nn.Linear(d_model, d_model),
            nn.GELU(),
            nn.Linear(d_model, d_model)
        )
        self.layer_norm = nn.LayerNorm(d_model)

    def forward(self, h: torch.Tensor, context: torch.Tensor) -> torch.Tensor:
        combined = torch.cat([h, context], dim=-1)
        z = torch.sigmoid(self.state_gate(combined))
        c = self.candidate_transform(h)
        h_next = self.layer_norm((1 - z) * h + z * c)
        return h_next


class NextorchReasoner(nn.Module):
    """Rede neural com busca latente e desacoplamento do espaço textual."""
    def __init__(self, vocab_size: int, d_model: int = 128, thought_steps: int = 4):
        super().__init__()
        self.d_model = d_model
        self.thought_steps = thought_steps
        
        self.embedding = nn.Embedding(vocab_size, d_model)
        self.thought_cell = LatentThoughtBlock(d_model)
        self.value_head = nn.Linear(d_model, 1)  # Estima estabilidade da inferência
        self.policy_head = nn.Linear(d_model, vocab_size)

        MuPScaleCoordinator.apply_mup_coordinates(self, d_model)

    def forward(self, x: torch.Tensor, capture_trajectory: bool = False):
        batch_size = x.size(0)
        h0 = self.embedding(x).mean(dim=1)
        
        h_current = h0
        trajectory = []
        
        # Test-Time Compute: iterações contínuas na variedade
        for step in range(self.thought_steps):
            h_current = self.thought_cell(h_current, h0)
            if capture_trajectory:
                trajectory.append(h_current)

        logits = self.policy_head(h_current)
        uncertainty = torch.sigmoid(self.value_head(h_current))
        
        if capture_trajectory:
            return logits, uncertainty, trajectory
        return logits, uncertainty

# 4. INTERPRETABILIDADE: SPARSE AUTOENCODER (SAE) COM CONTROLE PID
# =====================================================================
class IntegratedSAE(nn.Module):
    """
    Sparse Autoencoder (SAE) com reconstrução centrada no decoder e
    controle dinâmico de esparsidade via PID para eliminar o Latent Drift.
    """
    def __init__(self, d_model: int = 128, n_features: int = 512, target_l0: float = 16.0):
        super().__init__()
        self.d_model = d_model
        self.n_features = n_features
        self.target_l0 = target_l0
        
        self.b_dec = nn.Parameter(torch.zeros(d_model))
        self.encoder = nn.Linear(d_model, n_features)
        self.decoder = nn.Linear(n_features, d_model, bias=False)
        
        # Controlador PID de esparsidade
        self.l1_coeff = 1e-3
        self.kp = 1e-5
        self.ki = 1e-6
        self.kd = 1e-6
        self.integral_error = 0.0
        self.last_error = 0.0
        
        self.normalize_decoder()

    @torch.no_grad()
    def normalize_decoder(self):
        norms = self.decoder.weight.norm(p=2, dim=0, keepdim=True)
        self.decoder.weight.div_(norms.clamp(min=1e-8))

    def forward(self, x: torch.Tensor) -> Tuple[torch.Tensor, torch.Tensor]:
        x_centered = x - self.b_dec
        features = torch.relu(self.encoder(x_centered))
        x_recon = self.decoder(features) + self.b_dec
        return x_recon, features

    def update_pid(self, current_l0: float):
        error = current_l0 - self.target_l0
        self.integral_error += error
        derivative = error - self.last_error
        
        adjustment = (self.kp * error) + (self.ki * self.integral_error) + (self.kd * derivative)
        self.l1_coeff = max(1e-5, min(0.1, self.l1_coeff + adjustment))
        self.last_error = error

    def compute_loss(self, x: torch.Tensor, x_recon: torch.Tensor, features: torch.Tensor) -> torch.Tensor:
        recon_loss = nn.functional.mse_loss(x_recon, x)
        l0_pseudo = features.sign().sum(dim=-1).mean().item()
        self.update_pid(l0_pseudo)
        
        sparsity_loss = self.l1_coeff * features.norm(p=1, dim=-1).mean()
        return recon_loss + sparsity_loss


# Dicionário dinâmico de tradução das representações do SAE
FEATURE_ONTOLOGY: Dict[int, str] = {
    7: "Detecção de Encadeamento Hipotético (A -> B)",
    42: "Reconhecimento de Refutação por Reductio Ad Absurdum",
    128: "Fechamento Transitivo em Ordem Superior",
    256: "Eliminação da Dupla Negação",
}

def decode_sae_features(features: torch.Tensor, top_k: int = 2) -> List[str]:
    _, indices = torch.topk(features, top_k, dim=-1)
    results = []
    for idx in indices[0].tolist():
        results.append(FEATURE_ONTOLOGY.get(idx, f"Atributo_Abstrato_#{idx}"))
    return results

# 5. ORÁCULO DETERMINÍSTICO FORMAL (Z3 GATEWAY)
# =====================================================================
class FormalVerificationGateway:
    """Submete deduções a provas rígidas de refutação formal (UNSAT)."""
    @staticmethod
    def verify_deduction(premises: List[Tuple[int, int]], query_src: int, query_target: int) -> bool:
        solver = z3.Solver()
        variables = {i: z3.Bool(f"P_{i}") for i in range(16)}
        
        # Premissa inicial verdadeira
        solver.add(variables[query_src] == True)
        
        # Axiomas de implicação: p -> q
        for src, dst in premises:
            solver.add(z3.Implies(variables[src], variables[dst]))
            
        # Teste por Refutação Formal: Premises ∧ ¬Alvo
        solver.push()
        solver.add(z3.Not(variables[query_target]))
        
        # UNSAT significa que a refutação falhou => Teorema é estritamente verdadeiro
        status = solver.check()
        solver.pop()
        return status == z3.unsat

# 6. EXPANSÃO ELÁSTICA DE CAPACIDADE (NET2NET)
# =====================================================================
class Net2NetExpansion:
    """Amplia a largura da rede neural preservando estritamente a função de saída."""
    @staticmethod
    def widen_linear_layer(layer: nn.Linear, new_features: int) -> nn.Linear:
        old_out, old_in = layer.weight.shape
        if new_features <= old_out:
            return layer
            
        new_layer = nn.Linear(old_in, new_features, bias=layer.bias is not None)
        with torch.no_grad():
            new_layer.weight[:old_out] = layer.weight
            # Adiciona neurônios extras com pequenas perturbações aleatórias
            remainder = new_features - old_out
            idx = torch.randint(0, old_out, (remainder,))
            new_layer.weight[old_out:] = layer.weight[idx] + torch.randn_like(layer.weight[idx]) * 1e-4
            
            if layer.bias is not None:
                new_layer.bias[:old_out] = layer.bias
                new_layer.bias[old_out:] = layer.bias[idx]
        return new_layer

# 7. MOTOR DO CICLO RECURSIVO (AUTOPOIETIC REASONING LOOP)
# =====================================================================
class NextorchEngine:
    """Orquestrador do ciclo completo: Síntese, TTC, SAE, Verificação e Retreino."""
    def __init__(self, vocab_size: int = 16, d_model: int = 64):
        self.vocab_size = vocab_size
        self.d_model = d_model
        
        self.reasoner = NextorchReasoner(vocab_size=vocab_size, d_model=d_model, thought_steps=3)
        self.sae = IntegratedSAE(d_model=d_model, n_features=d_model * 4, target_l0=8.0)
        
        self.opt_model = optim.AdamW(self.reasoner.parameters(), lr=1e-3, weight_decay=1e-4)
        self.opt_sae = optim.Adam(self.sae.parameters(), lr=5e-4)
        
        self.verified_replay_buffer: List[Tuple[torch.Tensor, torch.Tensor]] = []

    def execute_self_improvement_cycle(self, n_problems: int = 5):
        print("\n" + "="*50)
        print("INICIANDO CICLO DE AUTOAPERFEIÇOAMENTO RECURSIVO")
        print("="*50)
        
        newly_verified = 0
        
        for p_idx in range(n_problems):
            # 1. Formulação do Problema Lógico
            n_steps = random.randint(2, 3)
            chain = random.sample(range(self.vocab_size), n_steps + 1)
            premises = [(chain[i], chain[i+1]) for i in range(len(chain) - 1)]
            start_var, expected_target = chain[0], chain[-1]
            
            # Tensor de entrada: [start_var, p1_a, p1_b, p2_a, p2_b, ...]
            input_seq = [start_var]
            for p in premises:
                input_seq.extend([p[0], p[1]])
            while len(input_seq) < 9:
                input_seq.extend([0, 0])
            input_tensor = torch.tensor([input_seq[:9]], dtype=torch.long)
            
            # 2. Inferência com Test-Time Compute (TTC)
            self.reasoner.eval()
            with torch.no_grad():
                logits, uncertainty, trajectory = self.reasoner(input_tensor, capture_trajectory=True)
                pred_target = torch.argmax(logits, dim=-1).item()
                
            # 3. Auditoria Mecanicista via SAE (Sem Latent Drift)
            final_thought = trajectory[-1]
            x_recon, features = self.sae(final_thought)
            thought_translation = decode_sae_features(features)
            
            # Treino contínuo do SAE nas ativações geradas (coevolução)
            self.sae.train()
            self.opt_sae.zero_grad()
            sae_loss = self.sae.compute_loss(final_thought, x_recon, features)
            sae_loss.backward()
            self.opt_sae.step()
            self.sae.normalize_decoder()

            # 4. Gateway de Verificação Formal Rígida (Z3)
            is_valid = FormalVerificationGateway.verify_deduction(premises, start_var, pred_target)
            
            status_symbol = "✔ UNSAT (VERDADE ABSOLUTA)" if is_valid else "✖ FALÁCIA / ALUCINAÇÃO"
            print(f"\n[Problema #{p_idx+1}] Proposta: P_{pred_target} | Verificador: {status_symbol}")
            print(f" ├─ Auditoria SAE: {', '.join(thought_translation)}")
            print(f" └─ Incerteza do Modelo: {uncertainty.item():.4f} | Coeficiente L1 SAE: {self.sae.l1_coeff:.6f}")
            
            # 5. Admissão Segura no Dataset
            if is_valid:
                target_tensor = torch.tensor([pred_target], dtype=torch.long)
                self.verified_replay_buffer.append((input_tensor, target_tensor))
                newly_verified += 1

        print(f"\n[Certificação]: {newly_verified} teoremas adicionados ao Replay Buffer.")
        print(f"[Buffer Total]: {len(self.verified_replay_buffer)} amostras formalmente provadas.")

        # 6. Retreino Supervisionado (Expert Iteration / STaR)
        if len(self.verified_replay_buffer) >= 2:
            print("\n[Retreino]: Atualizando pesos do Reasoner nos dados formalmente certificados...")
            self.reasoner.train()
            total_loss = 0.0
            
            for x_b, y_b in self.verified_replay_buffer:
                self.opt_model.zero_grad()
                pred_logits, _ = self.reasoner(x_b)
                loss = nn.functional.cross_entropy(pred_logits, y_b)
                loss.backward()
                self.opt_model.step()
                total_loss += loss.item()
                
            avg_loss = total_loss / len(self.verified_replay_buffer)
            print(f"[Retreino Concluído]: Perda Média = {avg_loss:.4f}")
